# CPSC 314 Assignment 2 - Feature Extension

Armadillo Dance Game

CONTROLS:

W -- move sphere forward

A -- move sphere left

S -- move sphere backward

D -- move sphere right

B - toggle dance on / off

Space - jump

Poses (while dancing)

Z -- Hands Up

X -- Lean

C -- Flex

V -- Disco

Songs

1 -- Song 1 (BPM = 128)

2 -- Song 2 (BPM = 130)

3 -- Song 3 (BPM = 130)

HOW TO PLAY

First choose a song using 1, 2 or 3 and then begin dancing by pressing "B". While dancing you can earn points.
There will also be prompts on the screen that tell you what pose to do. By performing the specific pose on time it will give you extra points and increase the combo counter.
The higher the combo counter the more points you will gain. If you press the wrong button the combo resets to x1. The goal of the game is to earn as much points as possible.

You can press B again to stop dancing and end the game.

EXTRA FEATURES
- ball pulses with song
- bpm slider
